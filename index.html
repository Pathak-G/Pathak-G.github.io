MSc dissertation, 2026Python, PyTorch, Optuna

Probabilistic federated learning for mental health prediction

Built a federated learning pipeline across four clinical groups (obesity, hypertension, diabetes and general), using 36,259 NHANES participants to predict depression from PHQ-9. I implemented Bayesian logistic regression with Laplace-approximated uncertainty for each group and combined the groups by precision weighting, then compared it with FedAvg and an MC Dropout network. Supervised by Prof. Pepijn van de Ven.

Result
Precision-weighted aggregation matched FedAvg (AUROC 0.699 against 0.701; balanced accuracy 0.644 for both) and added an uncertainty estimate for each group. The MC Dropout network reached 0.651 AUROC against 0.653 for a FedAvg network.
Limits
The uncertainty came at no measurable cost to accuracy, but it did not improve accuracy either. The data are survey data, not clinical records.
2026Python, AWS SageMaker, Lambda, API Gateway, RDS, Bedrock, Flask

Mental health risk prediction on AWS

Deployed a text classifier (TF-IDF with logistic regression, trained on the GoEmotions dataset) as a real-time SageMaker endpoint. A Flask web interface on EC2 calls it, with a serverless backend of Lambda, API Gateway and an RDS MySQL database. Amazon Bedrock generates a plain-language explanation of each prediction. Six AWS services in total.

Result
A working application from user input to prediction, explanation and stored result.
Limits
The explanations are written by a language model. I did not test how faithful they are to what the classifier actually relied on.
2026, group projectPython, XGBoost, scikit-learn, Pandas, weather API

Energy consumption prediction with limited data

I led data preprocessing for a 90,000-row dataset and added weather features (temperature, humidity and wind speed) from an API. We compared XGBoost, linear regression, random forest and gradient boosting, then ran an ablation across training-data fractions.

Result
XGBoost gave the lowest RMSE (0.6386). Adding synthetic training data made performance worse, which we attributed to distribution mismatch.
Limits
One dataset, so the ranking of models may not carry over to other data.
2026, two-person projectPython, TensorFlow, Keras, Gymnasium

DQN against Double DQN on Atari Atlantis

I led a comparison of the two agents over 1,800 episodes. Training was using the GPU poorly, so I traced the cause to a list-based replay buffer and replaced it with a pre-allocated NumPy circular buffer, which fixed the problem and cut memory use.

Result
Double DQN’s 100-episode average score was 14.2% higher.
Limits
One game and one training setup, so I would not generalise the 14.2% figure.
